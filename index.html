Behind the screen

The data structure doing each job.

  • Queue: three waiting lines, one per priority
  • Linked list: the status trail of each complaint
  • Stack: undo of status updates
  • BST: lookup by complaint ID
  • Searching: BST, binary and linear search
  • Sorting: bubble, selection, insertion, merge and quick sort
